### Ответы на вопросы

1. Чем статическая типизация Dart отличается от Python? Какое практическое
преимущество она даёт?

В Dart тип переменной известен на этапе компиляции, и компилятор проверяет его во время запуска. В Python тип определяется во время выполнения. Преимуществом является нахождение ошибок на этапе компиляции

2. Что означает String?? Чем отличается от String?

String? - nullable-тип, переменная может содержать null
String - non-nullable, не содержит null

3. Зачем в Dart final, если в Python можно просто договориться не менять
переменную?

Компилятор не даст изменить переменную после присвоения final, это исключает ошибки

4. Чем именованный параметр {required String name} отличается от
позиционного? Приведите пример вызова.

Именованный параметр передаётся по имени и заключается в {}
required делает его обязательным
Позиционный параметр передаётся по порядку
ПРИМЕР: describePet(name: 'Гектор', age: 1);
